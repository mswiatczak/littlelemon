# Little Lemon Restaurant Website

A modern, responsive restaurant website built with React for Little Lemon, a Mediterranean restaurant.

- [Technologies Used](#technologies-used)

## About

Little Lemon is a family-owned Mediterranean restaurant that brings traditional recipes to life with a modern twist. This website showcases their menu, allows reservations, and provides information about the restaurant.

## Technologies Used

- React 19.2.0
- React Router DOM 7.9.4
- React Icons 5.5.0
- CSS3 for styling
- Create React App 5.0.1

## Setup

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/littlelemon.git
   ```

2. Navigate to the project directory:

   ```bash
   cd littlelemon
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

5. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
